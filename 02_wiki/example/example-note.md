# Atomic Note — Format Example

This note exists to show what a wiki note looks like. The content below is fictional: it is here only to make the structure visible.

- One concept per file: if a source document covers three separate subjects, it becomes three notes, not one.
- Dense, direct body: concrete points, numbers where they exist, no filler. Bullet points instead of long paragraphs.
- Only what the source actually says. If the source does not cover a point, that point does not go in.
- The title describes the concept, not the document it came from: whoever searches in six months is searching for the concept.
