# templates — index

> Blank modules to fill in, reusable for any future project or note. Only the structure lives here: reusable content and methods live in `00_context/knowledge_pills/`.

- [[claude-template]] — rules skeleton for a new project's `CLAUDE.md`. Used by `03_skills/project-kickoff-procedure.md`.
- [[memory-template]] — state skeleton for a new project's `memory.md`. Same kickoff procedure.
- [[procedure-template]] — standard skeleton for an executable procedure file.
- [[framework-template]] — skeleton for a new reusable framework.
- [[hypothesis-template]] — skeleton for opening the hypothesis of a new service or product: target, problem, solution, market, pricing, validation criteria.
